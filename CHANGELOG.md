# Changelog

This file records notable user-facing changes to ReproForge. The project is currently pre-1.0, so interfaces may evolve while the report schema and security boundaries mature.

## Unreleased

No tagged public release has been declared yet. Future features, fixes, compatibility changes, and security-relevant behavior changes should be summarized here before release.

## Initial public foundation

The current foundation includes deterministic reproduction validation, Docker isolation, versioned evidence reports, fixture repositories, GitHub automation, and adapters/capability records for the initial coding-agent harness set. Earlier development history is preserved in Git.
